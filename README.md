# Anaglyph & Friends: Independent Edition

The established Anaglyph & Friends application with preserved original post-fork tools and independent replacements for the inherited application/model adapters. The working [Legacy Edition](https://github.com/udeudeude/Anaglyph-and-Friends) remains unchanged.

The integrated React studio includes the 17 original technique controls/defaults, depth editing and selections, imported stereo pairs, View-Master, phantograms, color reveal, layered composition/transparency, polarized projection, print pages/calibration, and folder batch processing. Feature presence is not a claim of device/physical-viewer equivalence. See [QA evidence](docs/QA_CHECKLIST.md) and [work state](docs/WORK_STATE.md).

## Run locally

```sh
python3 -m pip install -r backend/requirements-hosted.txt
npm ci --prefix frontend
VITE_FLASK_BACKEND_API_URL=. VITE_BROWSER_DEPTH=true npm run build --prefix frontend
AAF_BROWSER_DEPTH=true python3 backend/server.py
```

Open http://127.0.0.1:8010. V2 Small runs in the browser with GPU/CPU fallback; Python renders the original techniques. First use downloads the model. Browser inference transports float32 NPY, preserving precision.

For fully offline local inference, install PyTorch/torchvision compatible with your platform, run `python3 scripts/install_local_model.py`, build without `VITE_BROWSER_DEPTH`, and run with `AAF_BROWSER_DEPTH=false`. The pinned V2 Small model and source are verified during installation. The Mac workflow builds separate Intel/Apple Silicon applications with Python, frontend, model, source archive and notices bundled.

## Verify

```sh
python3 scripts/check.py
npm run build --prefix frontend
python3 scripts/verify_real_inference.py  # needs installed local model and torch
```
